Practical 1

Time Complexity Using Step Counting

Find the time complexity of algorithms using the step-counting method. This practical contains a non-recursive sum algorithm and a recursive factorial algorithm.

1A · Non-Recursive Sum

Add all elements of an array and count the steps.

def sum_algorithm(arr):

    step = 0
    total = 0

    step += 1

    for i in range(len(arr)):
        total = total + arr[i]
        step += 1

    print("Sum =", total)

    step += 1

    print("Total Steps =", step)
    print("Time Complexity = O(n)")


arr = [10, 20, 30, 40, 50]

sum_algorithm(arr)
Sum = 150 Total Steps = 7 Time Complexity = O(n)
Remember: The loop runs once for every element. If there are n elements, it runs n times, so the time complexity is O(n).

1B · Recursive Factorial

step = 0


def factorial(n):

    global step

    step += 1

    if n == 0 or n == 1:
        return 1

    step += 1

    return n * factorial(n - 1)


n = 5

result = factorial(n)

print("Factorial =", result)
print("Total Steps =", step)
print("Time Complexity = O(n)")
Factorial = 120 Total Steps = 9 Time Complexity = O(n)
Remember: It is recursive because factorial() calls itself. For n, it makes about n calls, so the time complexity is O(n).

Singly Linked List

Operations: insert at beginning, insert at end, delete first node, delete last node, search, update and display.

3A · Create the Linked List + Display

class Node:

    def __init__(self, data):
        self.data = data
        self.next = None


node1 = Node(10)
node2 = Node(20)
node3 = Node(30)

node1.next = node2
node2.next = node3

head = node1


def display(head):

    current = head

    while current is not None:
        print(current.data, end=" -> ")
        current = current.next

    print("NULL")


print("Original Linked List")
display(head)
Structure: 10 → 20 → 30 → NULL

self.data stores the value. self.next stores the link to the next node. head points to the first node.

3B · Insert at Beginning

print("\nInsert at Beginning")

newNode = Node(5)

newNode.next = head
head = newNode

Practical 4

Queue Using Array

Implement a Queue ADT using a Python list, with a maximum size of 5.

4A · Enqueue + Display + Main Program

queue = []

Max = 5


# Enqueue Operation

def enqueue(value):

    if len(queue) == Max:
        print("Queue Overflow")

    else:
        queue.append(value)
        print(value, "inserted into queue")


# Display Operation

def display():

    if len(queue) == 0:
        print("Queue is empty")

    else:
        print("Queue:", queue)


# Main Program

enqueue(10)
enqueue(20)
enqueue(30)

display()
FIFO
First In, First Out.
enqueue()
Adds an element to the queue.
Max = 5
Maximum queue size.
Queue Overflow
Occurs when the queue reaches its maximum size.
Practical 5

Circular Linked List

Implement a circular linked list and perform insertion, deletion, search, update and display operations.

5A · Create Circular Linked List + Display

class Node:

    def __init__(self, data):
        self.data = data
        self.next = None


node1 = Node(10)
node2 = Node(20)
node3 = Node(30)

node1.next = node2
node2.next = node3
node3.next = node1

head = node1


def display(head):

    current = head

    while True:
        print(current.data, end=" -> ")
        current = current.next

        if current == head:
            break

    print("Back to head")


print("Original Circular Linked List:")

display(head)
Circular structure: 10 → 20 → 30 → back to 10

The last node points to head, not None.
